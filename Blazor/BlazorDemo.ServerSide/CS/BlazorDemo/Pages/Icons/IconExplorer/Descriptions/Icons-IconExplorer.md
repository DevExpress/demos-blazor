DevExpress Blazor components allow you to use icons from the **DevExpress Icon Library** (available as Community Technology Preview). Icons are available in the following variations:

* **Icon Set**: Fluent, Desktop, BlazorClassic
* **Style**: Regular, Light, Filled
* **Color**: NoColor, Colored
* **Size**: 12, 16, 20, 24, 28, 32, 48

You can browse available icons in the following ways:

* Find icons using the built-in search panel.
* Filter icons by attribute.
* Display detailed icon information (including API identifiers that you can copy directly into code).
