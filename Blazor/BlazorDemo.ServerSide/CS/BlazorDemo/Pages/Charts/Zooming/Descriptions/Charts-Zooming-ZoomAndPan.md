Users can zoom and pan charts using the mouse wheel or touch gestures. To introduce zoom and pan operations within your DevExpress-powered app, add a [DxChartZoomAndPanSettings](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartZoomAndPanSettings) object and specify its [ArgumentAxisZoomAndPanMode](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartZoomAndPanSettings.ArgumentAxisZoomAndPanMode) and [ValueAxisZoomAndPanMode](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartZoomAndPanSettings.ValueAxisZoomAndPanMode) properties. To deactivate mouse wheel or touch gestures, set the [AllowMouseWheel](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartZoomAndPanSettings.AllowMouseWheel) or [AllowTouchGestures](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartZoomAndPanSettings.AllowTouchGestures) property to `false`.

Users can also pan charts along the argument axis using a scroll bar. To display a scroll bar, declare a [DxChartScrollBarSettings](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartScrollBarSettings) object and activate its [ArgumentAxisScrollBarVisible](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartScrollBarSettings.ArgumentAxisScrollBarVisible) option. Use the [ArgumentAxisScrollBarPosition](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartScrollBarSettings.ArgumentAxisScrollBarPosition) property to specify scroll bar position.

When a chart contains a large number of points, you can aggregate data to optimize performance. Add a [DxChartAggregationSettings](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartAggregationSettings) object to chart markup, set its [Enabled](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartAggregationSettings.Enabled) property to `true`, and specify the desired aggregation method via the [Method](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartAggregationSettings.Method) property.

When you zoom or pan the chart, axis visual ranges change. The [Chart](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChart-1) component allows you to react to these changes using the [VisualRangeChanged](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChart-1.VisualRangeChanged) event. You can use the following APIs to modify visual ranges:

* [DxChart.ResetVisualRange](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChart-1.ResetVisualRange) — Resets visual ranges for all axes to match a data range. 
* [DxChart.SetArgumentAxisVisualRange](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChart-1.SetArgumentAxisVisualRange(System.Collections.Generic.List-System.Object-)) — Sets the visual range for the argument axis.
* [DxChart.SetValueAxisVisualRange](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChart-1.SetValueAxisVisualRange(System.Collections.Generic.List-System.Object--System.String)) — Sets the visual range for a specific value axis.
* [DxChartAxisRange.StartValue](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartAxisRange.StartValue) — Specifies axis start value.
* [DxChartAxisRange.EndValue](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxChartAxisRange.EndValue) — Specifies axis end value.

In this demo, we leverage our built-in APIs and add accessibility-friendly zoom and pan operations (that conforms to the [Dragging Movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html) criteria). Click toolbar items to zoom/pan the chart plane or reset axes visual range.
