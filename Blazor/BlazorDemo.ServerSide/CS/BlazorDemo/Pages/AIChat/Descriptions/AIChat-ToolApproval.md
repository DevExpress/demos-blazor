DevExpress Blazor [AI Chat](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.DxAIChat) can access individual [AIContent](https://learn.microsoft.com/en-us/dotnet/api/microsoft.extensions.ai.aicontent) items generated by the AI service. You can inspect streamed content, render custom UI for specific content types, send structured follow-up messages, and hide/display messages in chat history.

This demo adds an approval step for AI-driven actions before a potentially damaging operation is executed. When the model requests a tool call, the app reads [message contents](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.BlazorChatMessage.Contents) and locates tool approval requests in [messages](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.ResponseReceivedEventArgs.Messages) received from the AI provider. The AI Chat component then [renders](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.DxAIChat.MessageContentTemplate) these requests as approval cards directly in the conversation.

After a user reviews all requests in the batch, the demo sends structured responses back to the model. The requested operation runs only after approval. The [BlazorChatMessage.Visible](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.BlazorChatMessage.Visible) property specifies whether individual messages remain visible in chat history.
