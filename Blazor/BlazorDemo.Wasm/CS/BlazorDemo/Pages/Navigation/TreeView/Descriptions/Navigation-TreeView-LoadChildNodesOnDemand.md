When you set [LoadChildNodesOnDemand](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTreeView.LoadChildNodesOnDemand) to `true`, the [TreeView](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTreeView) component loads child nodes when a parent node is expanded for the first time. Load Child Nodes on Demand mode reduces initial load time/memory consumption and is especially effective for large hierarchical data sets.

Load Child Nodes on Demand mode supports both bound (hierarchical data only) and unbound [TreeView nodes](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTreeViewNode). In bound mode, the [DxTreeViewDataMappingBase.HasChildren](https://docs.devexpress.com/Blazor/DevExpress.Blazor.Base.DxTreeViewDataMappingBase.HasChildren) property is required — the component uses it to determine whether to render expand buttons before a node is expanded for the first time. Use the [Selected](https://docs.devexpress.com/Blazor/DevExpress.Blazor.Base.DxTreeViewDataMappingBase.Selected) and [Expanded](https://docs.devexpress.com/Blazor/DevExpress.Blazor.Base.DxTreeViewDataMappingBase.Expanded) data mappings to set the initial selected/expanded state of nodes.
