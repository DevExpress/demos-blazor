This demo executes a two-step Shakespearean Poet pipeline and uses a custom response provider implementation (`WorkflowResponseProvider`). This provider delivers intermediate workflow events in real time. As the pipeline progresses, agents at each workflow step produce their output, and the DevExpress [Blazor AI Chat](https://docs.devexpress.com/Blazor/DevExpress.AIIntegration.Blazor.Chat.DxAIChat) component displays results immediately.
