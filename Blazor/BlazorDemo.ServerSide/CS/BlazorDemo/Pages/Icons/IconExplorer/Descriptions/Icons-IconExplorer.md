DevExpress Blazor UI components allow you to use icons from the **DevExpress Icon Library** (available as Community Technology Preview). The following icon variants are available:

* **Set**: Fluent, Desktop Classic, Blazor Classic
* **Style**: Regular, Light, Filled
* **Color**: Monochrome, Multicolor
* **Size**: 12, 16, 20, 24, 28, 32, 48

You can locate available icons in the following manner:

* Find icons by name or associated tag using our built-in search panel.
* Filter icons by attribute.
* Display detailed icon information (including API identifiers you can copy directly into code).
